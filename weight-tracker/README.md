# FitTrack 每日体重打卡与健康管理系统 (Daily Weight Tracker Web App)

一个极简高颜值、功能完善的 **每日体重打卡、BMI 健康分析与趋势曲线追踪系统**。

## ✨ 核心功能特色

1. **每日体重打卡记录**：
   * 支持记录每日体重 (kg)、体脂率 (%) 及饮食/运动备注说明。
2. **BMI 智能计算与健康评估**：
   * 输入身高与目标体重，自动计算 BMI 指数，并标注健康评级（偏瘦、标准、偏胖、肥胖）。
3. **动态 Canvas 体重变化趋势图表**：
   * 自动生成可视化折线变化曲线图，支持切换近 7 天、近 30 天及全量打卡趋势对比。
4. **目标达成度与连续打卡统计**：
   * 实时计算与初始体重的相差差值、距离目标体重的剩余千克数以及连续打卡天数。
5. **LocalStorage 离线自动保存**：
   * 打卡记录与个人身材目标自动保存在浏览器本地，安全不丢失。

## 🛠️ 技术栈
* **Core**: HTML5, Vanilla JavaScript (ES6+), Canvas API
* **Styling**: Vanilla CSS3 (Glassmorphism design, Flexbox/Grid Layout)
