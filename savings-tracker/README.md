# 365天存钱计划挑战 (Money Savings Challenge Web App)

一个极简、高颜值、有趣味的 **365天/N天存钱计划打卡系统**。

## ✨ 核心特色

1. **多种存钱模式**：
   * 365天阶梯存钱挑战（第1天存1元，第365天存365元，总计存下 ¥66,795 元）。
   * 100天每日百元计划（总计存下 ¥10,000 元）。
   * 52周递增计划（总计存下 ¥13,780 元）。
   * 自定义小目标模式（如购买手机/旅行基金）。
2. **互动格子阵打卡 (Interactive Grid Board)**：
   * 类似抽奖拆盲盒的富趣味性卡片打卡体验。
   * 支持随机抽取打卡按钮（随机挑选未存入格子）。
3. **实时数据仪表盘**：
   * 累计存入金额、完成百分比进度条、已打卡天数与连续打卡天数。
4. **LocalStorage 离线持久化**：
   * 自动在浏览器中保存您的打卡历史与存钱进度，无需担心数据丢失。

## 🛠️ 技术栈
* **Core**: HTML5, Vanilla JavaScript (ES6+)
* **Styling**: Vanilla CSS3 (Glassmorphism, Flexbox/Grid Layout)
