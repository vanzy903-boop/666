# Lumina 智能浴霸无级推光控制系统 (Bath Smart Light & Heater Controller)

一个高端极简风格的 **智能浴霸无级推光与暖房控温交互系统**。支持 0%-100% 触控无级推光调光棒、2700K - 6500K 暖光/冷白光无级色温调节、发热风道与发热丝拟真动画、预设场景推光以及多功能模式切换（暖风一/二档、换气、吹风、智能干燥）。

## ✨ 核心特色功能

1. **无级推光调光棒 (Push Dimmer Bar)**：
   * 支持鼠标按压拖拽与触控无级滑动调节（0% - 100%）。
   * 实时背景与主灯拟真光晕效果渲染。
2. **2700K - 6500K 无级调色温**：
   * 基于黑体辐射 Kelvin 色温计算引擎，精确呈现暖黄光至冷白光的灯效变化。
3. **浴霸设备视觉拟真 panel**：
   * 主灯光效、换气扇旋转动画（CSS 3D / Spin）、加热丝发热红光脉冲联动。
4. **推光场景一键预设**：
   * 舒适洗浴、强劲暖房、夜起微光、美妆护肤等快速切光模式。
5. **实时功率与定时器计算**：
   * 包含定时自动关机控制与实时功率计算面板。

## 🛠️ 技术栈
* **Core**: HTML5, Vanilla JavaScript (ES6+)
* **Styling**: Vanilla CSS3 (Custom Properties, Glassmorphic Design, Flexbox/Grid Layout)
* **Fonts**: Outfit & Noto Sans SC (Google Fonts)

## 🚀 部署与使用
直接双击打开 `index.html` 即可在浏览器中体验。或部署至 GitHub Pages 查看线上效果。
