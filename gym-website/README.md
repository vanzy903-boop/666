# TITAN FIT 泰坦极速健身中心宣传官网 (Hardcore Cyber Gym Web Project)

一个高端极简、暗黑赛博风格的 **24H 智能健身会所官方宣传网站**。包含会所硬件优势展示、高能特色团课、金牌私教团队展示、尊享会员卡种选购以及在线免费体验通卡预约弹窗。

## ✨ 核心页面模块

1. **Hero 视觉冲击头部**：高燃标语、黑橙对比调色、数据计数器动画（3,500+ 会员，45+ 资深教练）。
2. **硬核设施区 (Facilities)**：展示重型自由力量区、悍马器械、50m 恒温泳池、InBody AI 智能体测等。
3. **特色课程 (Featured Classes)**：TITAN HIIT 极速燃脂、巨型组力量塑形、热瑜伽与核心拉伸。
4. **金牌教练团队 (Pro Trainers)**：展示 NSCA / ACE / ACSM 认证教练简介与特长标签。
5. **会员卡种选购 (Membership Plans)**：月度体验卡、黑金尊享年卡（推荐）、季度通卡。
6. **3天免费体验卡在线预约表单**：支持在线填写姓名、电话与健身目标，提交后触发浮层模态弹窗。

## 🛠️ 技术栈
* **Core**: HTML5, Vanilla JavaScript (ES6+)
* **Styling**: Vanilla CSS3 (CSS Custom Properties, Glassmorphic UI design, Responsive Layout)
* **Design & Typography**: Outfit & Noto Sans SC (Google Fonts)
